MCP Server — Access Rights Management

Java Spring Boot Spring AI RBAC PostgreSQL

AI agents are increasingly given access to real tools and systems through the Model Context Protocol (MCP) — but MCP itself doesn't answer who should be allowed to call which tool. This project designs and implements role-based access control (RBAC) directly inside an MCP server, rather than relying on an external gateway that can be bypassed or misconfigured.

Built on Spring Boot and the Spring AI MCP Server Boot Starter, the access control layer sits directly in the request lifecycle — token validation, RBAC checks, and audit logging — and is packaged as a reusable Spring Boot starter, in the spirit of spring-boot-starter-security.

The design is evaluated against three scenarios with different trust levels and tool surfaces: an internal enterprise agent, a low-trust customer-facing agent, and a multi-agent setup where a supervisor delegates to sub-agents that need narrower permissions — the case that stresses permission-narrowing the hardest.

This is an ongoing Projektarbeit at FH Dortmund, feeding into a planned bachelor's thesis. No public repository yet — it'll be linked here once implementation starts.
