Project 03

2D Game — C# / MonoGame

C# MonoGame OOP Design Patterns

A 2D game built from scratch in C# using the MonoGame framework, without a higher-level engine on top.

Implements the core game loop, an entity system, collision detection, and input handling — with GoF design patterns (State, Observer, Strategy) applied throughout the architecture rather than bolted on afterward.

This started as a working game and was deliberately refactored to apply those patterns correctly — the point was learning where each one actually earns its place, not pattern-spotting for its own sake.
