Project 04

Portfolio Website

HTML/CSS/JS GitHub Pages

This site. Built from scratch with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies — on purpose, so the fundamentals (layout, the DOM, browser APIs) stay visible instead of hidden behind a framework.

Scroll-reveal is a single IntersectionObserver watching every .reveal element and staggering the fade-in by index — no animation library. Layout is plain responsive CSS with breakpoint-driven rules for the grid and nav, the same media-query-first approach used on the Student-Manager frontend, just without a component framework underneath it.

Deployed via GitHub Pages, auto-published on every push to main. The dark, grid-textured design and card-based sections are meant to read like a well-organized codebase: clear sections, consistent spacing, minimal decoration.
