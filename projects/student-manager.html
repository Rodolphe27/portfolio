Project 02

Student-Manager — Fullstack

Java Spring Boot React TypeScript PostgreSQL Supabase Railway Vercel Docker GitHub Actions

A full-stack student management system built for FH Dortmund, covering student, course, and enrollment management for three roles — student, teacher, and admin. The point of the project wasn't just the feature set: it was a deliberate run through the full software development lifecycle, from an issue-driven backlog through implementation, testing, containerization, CI, and independently deploying every layer — a learning project, not a production system, and treated with the same rigor either way.

The backend is Spring Boot 3, organized as a feature-based package structure — auth, student, course, and enrollment each own their controller, service, and repository — on top of a standard layered architecture (controller → service → repository) with persistence entities kept separate from API-facing DTOs. Authentication is stateless JWT, enforced by a custom filter in the Spring Security chain, and a centralized exception handler maps domain exceptions to consistent HTTP error responses.

The frontend is React 19 with TypeScript. Auth state lives in a Context provider exposed through a custom useAuth hook, route access is enforced by a ProtectedRoute wrapper component, and every API call goes through a per-domain service layer with Axios interceptors that attach the JWT and handle 401s globally — keeping API, state, and UI concerns separate. Layout is Tailwind CSS, mobile-first, with the sidebar collapsing into a drawer below the tablet breakpoint.

Each layer is deployed independently, on purpose, to learn how that actually works: PostgreSQL on Supabase, the Spring Boot API containerized and deployed on Railway, and the React frontend on Vercel — wired together with environment-specific config rather than one bundled Docker Compose stack (that's still how local development runs). A GitHub Actions CI pipeline type-checks and builds the frontend and builds the backend on every push.
