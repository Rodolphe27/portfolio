Project 02

Student-Manager — Backend

Java Spring Boot React PostgreSQL Docker GitHub Actions

A full-stack student management system built for FH Dortmund, covering student, course, and enrollment management for three roles — student, teacher, and admin.

The backend is Spring Boot 3 with JWT authentication and role-based authorization; the frontend is React 19 with TypeScript, including real-time search, status filtering, and a responsive layout that collapses into a mobile drawer below the tablet breakpoint.

Fully containerized with Docker Compose, with a GitHub Actions CI pipeline running the build on every push.
