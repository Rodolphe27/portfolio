# Rodolphe Loic Souassi Tatang — Portfolio

Personal portfolio website. Vanilla HTML/CSS/JS, no frameworks, no build tools.

Deployed via GitHub Pages: https://rodolphe27.github.io/portfolio/

## Structure

- `index.html` — single-page portfolio (hero, skills, projects, experience, education, contact)
- `projects/*.html` — per-project detail pages
- `css/style.css` — all styles
- `js/main.js` — scroll-reveal + mobile nav toggle
- `assets/og-image.*` — social preview image (`og-image.svg` is the source; `og-image.png` is what's referenced)
- `favicon.svg`

Auto-published on every push to `main`.
